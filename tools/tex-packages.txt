# TeX Live packages the book needs on top of a fresh TinyTeX.
#
# One package per line: the tlmgr package name, then a file it provides.
#   * tlmgr installs the first column        (tools/setup_windows.ps1, CI)
#   * kpsewhich looks for the second column  (tools/check_env.py), which works
#     with any TeX distribution, not only TinyTeX.
# Single source of truth: .github/workflows/build.yml reads this file too.
#
# Why each group is needed:
#   figures (diagrams/*.tex are compiled by plain lualatex, outside Quarto, so
#   Quarto's auto-install never applies) and the Kindle edition's equations:

luatexbase      luatexbase.sty   # babel's LuaTeX backend; minimal TinyTeX omits it
